# Kyana Hay Portfolio Website

## Description
This project is a personal portfolio website for Kyana Hay. It presents her background, career goals, and contact information in a clean, professional format.

The website highlights both her analytical ambitions as a future data analyst and her entrepreneurial goals as a nail technician.

## Features
- Personal introduction with profile image
- Contact section with clickable email and external links
- Career vision section outlining goals and ambitions
- Clean and modern design using a consistent color theme
- Styled layout with responsive spacing and readability

## Technologies Used
- HTML5
- CSS3

## File Structure
- `index.html` – Main structure and content of the website
- `styles.css` – Styling, layout, and color theme
- `Kyana.jpeg` – Profile image

## Design Details
- Uses a USF-inspired color scheme (green and gold)
- CSS variables are used for consistent styling
- Header and footer share a unified design
- Profile image is styled as a circular portrait
- Links include hover effects for better user experience

## How to Run
1. Download or clone the repository
2. Ensure all files are in the same folder
3. Open `index.html` in any web browser

## Concepts Demonstrated
- Semantic HTML structure
- CSS styling and layout design
- Use of CSS variables
- Linking external resources
- Image styling and positioning
- Basic responsive layout practices

## Notes
- This is a static website (no JavaScript functionality)
- Designed as a simple portfolio project
- Can be expanded with additional sections such as projects, experience, or skills
